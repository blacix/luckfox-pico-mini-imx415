The ISP Tuning (IQ) File:Target File: imx415_*.json (e.g., imx415_CMK-OT2119-PC1_30IRC-F16.json or similar).Source: Unpack oem.img or rootfs.img from the Pico Zero firmware package (or pull it directly from the Luckfox SDK repository under external/camera_engine_rkaiq/iqfiles/isp3x/).Compatibility: 100% compatible. The RV1103 and RV1106 share the exact same Rockchip ISP3.2 architecture and rkaiq library.The Kernel Driver Module (imx415.ko):Target File: imx415.ko.Source: Located inside /oem/usr/ko/ inside the Pico Zero’s oem.img.Compatibility: If the kernel vermagic and symbol versions match your current 5.10.110 Buildroot kernel, you can place it directly in /oem/usr/ko/ on your board. If insmod fails with an invalid module format or unresolved symbol error, the driver will need a fast compile from the Luckfox SDK.The 2-Lane Device Tree Configuration:The Pico Zero device tree uses 4 MIPI lanes (data-lanes = <1 2 3 4>;). The RV1103 only supports 2 MIPI lanes (data-lanes = <1 2>;). The DTB node must declare 2 lanes, or the internal D-PHY will fail to lock.
